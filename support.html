Before reporting a problem

  • Refresh the page and try again in a private/incognito browser window.
  • Confirm that your browser allows JavaScript and network requests to PTD Today services.
  • If a Cosmos station does not open, try the same question again from the Cosmos home view.
  • If the ChatGPT plugin does not respond, start a new ChatGPT conversation and invoke PTD Today Cosmos again.

What to include in a support report

To help diagnose an issue, include the question you asked, the approximate time, the device/browser you used, and a screenshot of the problem. Do not send passwords, API keys, authentication tokens, payment data, or other sensitive secrets.

Contact

For support inquiries, feature feedback, or a request concerning shared Cosmos content, contact PTD Today through the official PTD Today LinkedIn profile linked above. When available, additional support channels may be published on this page.

Privacy and data requests

For questions about how PTD Today Cosmos handles information, or to request access to or deletion of PTD Today-controlled data associated with a shared Cosmos station, review the Privacy Policy and contact PTD Today through the support channel above.
