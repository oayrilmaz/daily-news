How do I use only the external display with my MacBook Pro lid open on Lion?

The short answer

Use Terminal command sudo nvram boot-args= iog=0x0 to enable external display.

Explore the answer

On Mac OS X Lion, to use only an external display with your MacBook Pro lid open, you can change a system setting via Terminal. Enter the command 'sudo nvram boot-args= iog=0x0' to revert to the behavior before Lion, which allows using just the external display while the lid is open. If you want to undo this change later, you can either reset the parameter with 'sudo nvram -d boot-args' or reset the PRAM by pressing Cmd+Option+P+R during startup. This method modifies the boot arguments stored in NVRAM to control display behavior.
