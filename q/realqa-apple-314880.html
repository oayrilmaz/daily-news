Is it possible to add a horizontal line to apple notes on a mac?

The short answer

No native horizontal line feature; use an image workaround instead.

Explore the answer

Apple Notes on Mac does not have a built-in option to insert a horizontal line. A common workaround is to create a thin, wide image (e.g., 2400x6 pixels) filled with a solid color and save it as a .jpg or .png file. You can then copy and paste this image into your note where you want the horizontal line. This image will adjust its width with the Notes window, providing a visual horizontal separator. To streamline this process, you can use tools like TextExpander or create an Automator service with AppleScript to insert the image via a keyboard shortcut. This method is not perfect but is currently the best available solution to simulate a horizontal line in Apple Notes on Mac.
