What is causing this Cloudflare error and how to access the site on Safari Mac?

The short answer

HTTP links cause errors in Safari; use HTTPS links to access the site.

Explore the answer

The Cloudflare error occurs because the webpage contains links using the HTTP protocol, which Safari does not handle well when opening in a new tab. Specifically, Safari fails to open target pages linked via HTTP, leading to the error. Editing the links to use HTTPS instead resolves the issue, allowing the page to open correctly in a new tab. This behavior appears to be a limitation or bug in Safari's handling of HTTP links when the default action is to open links in new tabs. To fix this, the website owner should update the links to HTTPS, or Apple may need to address the browser's handling of such links. End users have limited options to resolve this issue themselves.
