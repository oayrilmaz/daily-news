Restricting Command+tab options to only apps that are in the current space

The short answer

Use Control + F4 to cycle through apps in the current Space only.

Explore the answer

To restrict app switching to only those in the current Space on macOS, you can use the keyboard shortcut Control + F4. This shortcut cycles through the applications that are open in the active Space, rather than all open apps across all Spaces. You can customize this shortcut by going to Keyboard preferences, then Keyboard Shortcuts, and selecting Keyboard Text Input. There, you will find the option labeled 'Move focus to active or next window,' which controls this behavior. Some users remap this shortcut to Control + ` for easier access, but the default is Control + F4. This method allows you to switch between apps confined to your current desktop environment without cycling through apps in other Spaces.
