Can I get the CPU temperature and fan speed from the command line in OS X?

The short answer

Yes, use 'powermetrics' or Intel Power Gadget on macOS command line.

Explore the answer

You can obtain CPU temperature and fan speed information on macOS using the command line utility 'powermetrics'. Running 'sudo powermetrics --samplers smc' provides various system metrics including CPU die temperature, which can be filtered using grep. For example, 'sudo powermetrics --samplers smc | grep -i CPU die temperature' shows the CPU temperature. Additionally, Intel provides the Intel Power Gadget, a tool that can be installed and launched to monitor CPU metrics including temperature and fan speed. These methods have been tested on macOS Mojave and provide reliable access to hardware monitoring data from the command line or via a graphical interface.

Grok's perspective

Command-line retrieval of CPU temperature and fan speed on macOS can vary by hardware model and system version, with no guarantee of consistent or direct access across all setups.
