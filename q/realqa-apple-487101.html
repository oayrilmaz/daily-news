Does Rosetta become uninstalled after updating to macOS 27.0?

The short answer

Yes, Rosetta is removed when upgrading to macOS 27.0 and must be reinstalled.

Explore the answer

When upgrading to macOS 27.0, Rosetta is removed and does not remain installed automatically. This behavior was identified as a bug in version 27.0. To use Rosetta after the upgrade, users need to reinstall it either by clicking the install prompt that appears when launching an Intel-based application or by running the command 'softwareupdate --install-rosetta' in the Terminal. This issue was addressed in macOS 27.2, which reinstalls Rosetta automatically if it was installed before the upgrade. Additionally, macOS 28 will limit Intel support to legacy Intel-based games, but details on this are not yet available.
